# Diploma Thesis Proposals – Signal Processing & Biomedical Technology Unit (SPBTU)

This repository contains available diploma thesis proposals offered by the **Signal Processing and Biomedical Technology Unit**, aiming to inform students and facilitate access to research opportunities.

## Location

**Building D, 6th floor, Wing B, Office 26**  

## Application Form

To apply for a topic, please use the following form and select the correct proposal number:  
[Link](https://docs.google.com/forms/d/e/1FAIpQLSe08hw9Z0LANej63cjehx1ELBqKeMNK7EtdYA9n1JgNS0-UAw/viewform?usp=header)

If you wish to apply for more than one available subject, please submit a **separate form for each**.
